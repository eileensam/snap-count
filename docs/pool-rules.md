# Pool Rules

Snap-Count tracks a friend-group NFL pool that started in 1997, using a format from a Forbes magazine article. The format hasn't changed since; only team prices and participants shift year to year.

## Entry

- $25 entry fee per player, paid to the commissioner (not tracked by this site, see [decisions.md](decisions.md))
- Each player picks any number of teams whose combined price is ≤ $250. No cap on team count.
- Prices are set each season by the commissioner from current betting markets. This year's prices and pick deadline live in [roadmap.md](roadmap.md) (season-specific, so not duplicated here).

## Scoring

- Regular season: 1 point per win, 0.5 per tie.
- Regular-season points carry into the postseason.
- Postseason: 3 points per wildcard-round win, 3 per divisional-round win, 5 per conference championship win, 5 for the Super Bowl win.

## Prizes

- Highest regular-season point total alone (excluding postseason points) wins **10%** of the pot.
- Overall winner (regular season + postseason combined) wins **75%**.
- Overall 2nd place wins **10%**.
- Lowest overall scorer gets a **5%** "booby prize."

## Groups

- **Full League**: everyone in the pool, historically ~20+ participants.
- **Small Group**: a more engaged, competitive subset within the Full League. Checks the site more often; the leaderboard highlights their standings distinctly.

Both groups use the same site and the same rules above.
